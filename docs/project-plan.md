# Project Plan — Nexus v2

## Overview

Complete rebuild of the Nexus PPM platform using Flutter (Web) + Supabase.

## Stack

- **Frontend:** Flutter Web (responsive)
- **State:** Riverpod 3 (code generation)
- **Backend:** Supabase (Auth, PostgreSQL, Realtime, Edge Functions)
- **RBAC:** Role-based access with view modes (own/team/global)
